## Question

What does credible evidence (cognitive science, learning research, podcast listening data) say about the best length for an audio learning episode? How long can listeners focus and retain information, and what length should the default be (owner suggests ~20 min)? Include when to split into parts.

## Resolution

Closed 2026-10-29. Findings in `research/01-episode-length-evidence.md`. Default ~20 min (15-25), built from 4-5 segments of ~4-6 min with recall prompts; hook in first 60-90 s; split only past ~25-30 min or when sub-questions stand alone (max 2-3 parts). No direct audio-only evidence exists; length is a tunable default. Several sources were read via summaries only and need verification before quoting.
